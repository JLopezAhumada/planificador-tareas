# Planificador de Tareas

Aplicación web para registrar y organizar tareas. Permite crear una tarea con nombre, descripción, fecha de entrega y estado, y ver todas las tareas en tarjetas. Construida con HTML5, Bootstrap 5 y JavaScript.

## Sprint 1

- Tarea 1: formulario para registrar tareas.
- Tarea 2: tarjeta de tarea y lista con cinco tareas de ejemplo.
- Tarea 3: validación del formulario con JavaScript (`validFormFieldInput`) y mensajes de error.
